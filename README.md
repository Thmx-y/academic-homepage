# 个人学术主页

唐德军的个人学术主页，用于展示教育经历、主要课程、竞赛奖项、学术项目和联系方式。

网站默认中文，支持切换英文，使用 Astro、TypeScript 和原生 CSS 构建，通过 GitHub Pages 自动部署。

访问地址：[中文主页](https://thmx-y.github.io/academic-homepage/) · [英文主页](https://thmx-y.github.io/academic-homepage/en/)

## 主要目录

- `src/data/`：个人资料、奖项、经历和项目数据。
- `src/components/`：页面组件。
- `src/styles/`：排版与样式。
- `public/`：网站静态文件。
- `.github/workflows/`：自动构建与部署配置。

专业课资料使用独立仓库管理，不在本仓库发布。
